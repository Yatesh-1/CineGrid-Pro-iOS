# CineGrid Pro — Professional Camera Studio & Photography Engine

**CineGrid Pro** is a high-performance, cross-platform cinematography and photography application engineered with React 19, TypeScript, Vite, Tailwind CSS, Capacitor 8, and real-time WebGL shader pipelines.

Designed for professional directors of photography, commercial photographers, and content creators, CineGrid Pro combines the tactical ergonomics of high-end cinema hardware (Blackmagic Camera, ARRI) with an expansive composition engine, Lightroom-inspired photo editing suite, and a zero-crash 3D LUT grading engine.

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Run Quality Gates
```bash
# High-speed Oxlint check
npm run lint

# Run all 90 automated tests (17 test suites)
npm test

# Verify production compilation
npm run build
```

### 4. Create an Automated Snapshot Backup
```bash
npm run backup
```
